# 请 WebCodex 喝杯咖啡 ☕

[English](SPONSORSHIP.md) | [简体中文](SPONSORSHIP.zh-CN.md)

WebCodex 是一个免费、开源的项目。如果它帮你节省了时间，或者让 AI 编程更方便，欢迎请维护者喝杯咖啡，支持后续开发、测试和维护。

**完全自愿，不赞助也不影响任何功能或社区支持。** 点个 Star、反馈问题、分享项目或提交 PR，同样是很大的帮助。

## 你的支持会用在哪里？

主要用于日常维护、跨平台测试、构建和发布，以及服务器等必要开销。赞助不会换取功能优先级、特殊权限或代码合并承诺。

## 展示与独立性

赞赏信息仅放在仓库 README 和本文档中，不放入 Desktop 或 Runtime 弹窗，也不因赞赏加入第三方追踪。赞助不会影响安全判断、代码评审、发布决策或项目方向。

## 其他支持方式

如果你能提供测试设备、CI 资源、代码签名或其他基础设施支持，也欢迎通过 [GitHub Issues](https://github.com/yyjeqhc/webcodex/issues) 交流；请勿在公开 Issue 中发布凭据或敏感信息。

感谢每一位使用、分享和贡献 WebCodex 的朋友。
