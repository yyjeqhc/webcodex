# 本机 Computer Control

Windows Desktop 在原生托盘悬停提示中显示 Computer 活动。保存的环境包含本机 Runner 时，
**暂停 Computer Control** 会阻断使用该 Runner 的所有远程客户端的后续原生输入。
**恢复 Computer Control** 需要明确的本机操作。关闭 Desktop 主窗口后，托盘和 Runner
继续运行时仍可使用这些控制。

状态区分观察、控制请求、空闲、控制已暂停、控制已暂停但仍在观察，以及仍有在途控制的
正在暂停状态。短请求结束后会单独显示 1.5 秒的最近活动提示。本机状态无法取得时显示
状态不可用。

暂停覆盖指针移动和点击、键盘及文本输入、窗口激活、应用启动、剪贴板写入和语义控件操作。
截图、辅助功能和窗口查询、剪贴板读取仍遵循原有观察权限。已经进入原生执行的操作不会
因暂停而撤销；在途控制结束前不能恢复。

托盘菜单只保留一个 Computer 操作：暂停，或暂停后的恢复。
屏幕边缘提示在控制活动期间及结束后 1.5 秒内自动显示，此时按本机物理 **Esc** 键即可暂停
控制。快捷键不会恢复控制，AI 等程序注入的 Escape 按键也不会触发暂停；前台应用仍能接收
Escape。仅观察时不启用快捷键或边缘提示。
边缘提示最多覆盖十六个连接的显示器，不激活窗口、不拦截指针，并请求 Windows 截图排除。
实际截图排除和全屏显示效果取决于 Windows 合成器及截图提供方。

## 执行与恢复

`webcodex-computer-control` 管理本机门禁和有界管理协议；`webcodex-computer` 保留原生目标
校验及 Browser 用户接管约束。Runner 与交互式 Helper 在请求准入和原生副作用入口使用
同一门禁。恢复 Computer Control 不会解除 Browser 用户接管。

已准入请求在等待输入锁或原生目标预检期间仍可被暂停撤销。取得锁后，以及首次原生副作用
提交点，都会复核同一暂停状态和控制版本。提交被拒绝时不会执行输入，也不会消耗指针截图
版本。已经提交的序列可以完成按键释放和原生清理，并保留原有成功或结果不确定的语义。

新增的 `computer_local_control` 能力独立声明软件支持，交互式 Helper 尚未就绪时也可上报；
控制请求会等待首次控制版本。Server 为控制请求绑定 Runner 上报的本机控制版本，
并在准入、出队和原生执行时保留该版本。
暂停、恢复、Runner 替换和 Helper 会话失效都会淘汰旧控制请求，包括不绑定窗口或元素句柄
的剪贴板写入。旧请求会被拒绝；本机恢复后，需要观察当前桌面状态并发起新请求。

推送传输中，读取当前控制版本、元数据入队及成功上报记录与注册重置共用同一临界区。
心跳和请求结果的并发上报不会把旧版本排在新版本之后，却记录新版本已上报。
入队失败时保留原上报记录，后续可以重试。

暂停设置独立于 Computer 不透明 ID 保存。Runner 或 Helper 重启后保留已确认的暂停状态，
并生成新控制版本。保存状态损坏时无法启用输入。暂停持久化失败时，内存门禁保持关闭并返回
错误；再次尝试必须成功持久化后才能确认成功。
门禁会保留保存失败状态，直到成功保存。Desktop 提示后续输入已阻断、暂停状态未保存，
并说明重启后可能恢复控制；菜单提供“重试保存暂停 Computer Control”，而非恢复。
普通状态轮询及 Desktop 重连不会确认尚未保存的暂停。缺少持久化失败字段的旧版本状态视为
不可用，不推断为已持久保存；Desktop 与 Runner 应一起更新。

Windows 本机管理管道只接受状态读取、暂停和恢复，限定交互式会话，拒绝远程管道客户端，
授权创建账户和 LocalSystem。Desktop 校验服务端可执行文件和已观察的控制版本。
管理管道独立于串行原生操作管道，不携带凭据、截图、窗口标题、输入文字或剪贴板内容。
远程 Computer 工具不提供恢复入口。此门禁只约束 WebCodex Computer 操作，并不是
对另行授权的 Shell/脚本执行提供的操作系统沙箱。以相同交互式用户身份运行的代码
仍可能通过原生系统接口输入，或访问仅限该账户的本机管理管道；因此不能将本机暂停
表述为针对同账户不可信代码的安全隔离。

请一起更新 Desktop、Runner 和 Server。新版受管理 Windows Runner 会拒绝旧 Server
发出的无版本控制请求，观察契约继续保留。旧 Runner 保持既有行为，不提供本机暂停保证。
共享状态机独立于平台；本机管理传输和 Desktop 控制当前要求 Windows。

在没有配置 Computer Helper 的情况下，若 Windows Runner 运行于非交互式 Session 0，
仍可提供 Shell、文件和 Job 工具，但所有原生 Computer 控制都保持禁用；此时没有
本机管理管道或恢复入口。其他管道初始化错误仍然显式失败，不会偷偷启用输入。

聚焦的原生管道测试使用临时本机状态，覆盖服务端身份、暂停和恢复、过期版本、重复占用及
客户端断开后的恢复。真实 Desktop 托盘显示、快捷键注册、多屏及全屏行为、截图排除效果
需要原生环境单独验收。
